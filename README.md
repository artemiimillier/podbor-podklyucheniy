# Подбор подключений для Hermes Agent

Бесплатный навык 0.3.0: подбирает MCP, API и CLI под конкретную бизнес-задачу. Проверяет уже доступные инструменты, исследует подходящие решения на рынке, сопоставляет функции и считает стоимость вашей нагрузки. Если это оправдано, предлагает связку разных провайдеров с распределением по бесплатным квотам, качеству и цене. Результат — рекомендация с источниками, расчётом, правами и безопасным первым тестом. Навык сам ничего не устанавливает и не авторизует.

## Установить одной просьбой агенту

Скопируйте весь блок в разговор с Hermes Agent:

```text
Установи бесплатный навык «Подбор подключений» из https://github.com/artemiimillier/podbor-podklyucheniy. Сначала прочитай README.md и SKILL.md, проверь содержимое и определённую Hermes папку навыков активного профиля. Если одноимённый навык уже есть, не перезаписывай его без моего согласия. Используй штатную команду: hermes skills install https://raw.githubusercontent.com/artemiimillier/podbor-podklyucheniy/v0.3.0/SKILL.md --yes. Не обходи блокировку сканера безопасности. Проверь установленную версию 0.3.0 и наличие SKILL.md, references/checks.md, references/cost-and-routing.md и templates/recommendation.md. Затем найди навык через доступный в этой сборке список навыков и прочитай его. Если текущая сессия ещё не видит новый навык, попроси открыть новый разговор. После установки начни с вопроса: «Какую задачу вы хотите решить и с каким сервисом?» Никакие внешние сервисы пока не подключай.
```

Если уже установлена 0.2.0 по закреплённой ссылке, обычная проверка обновлений по этой ссылке не найдёт 0.3.0. Попросите агента прочитать новую версию, показать отличия и с вашего согласия обновить именно этот навык из ссылки 0.3.0, сохранив ваши собственные правки отдельно.

Ручная загрузка архива и распаковка не нужны. Агент выполняет установку в своей среде исполнения: при удалённом Hermes это сервер, а не ноутбук с Desktop. Перед установкой можно попросить агента только прочитать навык, без сохранения.

## Как пользоваться

Например: «Подбирай подключения под задачу без лишних установок. Нужно один раз прочитать публичную страницу. Нужен ли новый MCP?»

Для сложной задачи укажите результат, нужные действия, разовый или регулярный запуск, примерный объём, бюджет и ограничения на данные. Например: «Нужно регулярно извлекать текст и таблицы из 10 000 PDF-страниц в месяц. Сравни MCP, API и локальные CLI по качеству и полной стоимости. Проверь, выгодно ли использовать бесплатные квоты разных провайдеров; дай распределение нагрузки, платный остаток и первый тест без установки». Не передавайте пароли, токены или коды входа в разговор.

Одна задача не обязана означать один платный сервис. Но несколько интерфейсов одного API обычно расходуют общий баланс, пробные кредиты могут быть разовыми, а разные результаты потребуют нормализации. Навык проверяет эти условия и может рекомендовать одного поставщика, если дополнительные подключения не окупаются.

## Что входит

- `SKILL.md` — инструкция навыка.
- `templates/recommendation.md` — необязательный шаблон короткого ответа.
- `references/cost-and-routing.md` — сравнение единиц стоимости, бесплатных квот и маршрутизации.
- `references/checks.md` — приёмочные задания, не заявление о пройденных испытаниях.
- `LICENSE` — MIT.

Зависимости и ключи для установки навыка не нужны. Для подбора нужны доступные инструменты чтения публичных источников. Каталог кандидатов: https://smyslokod.ru/mcp. Каждое подключение необходимо проверять отдельно: карточка в каталоге не означает, что доступ уже работает в Hermes.

## Ограничения проверки

В 0.3.0 обновлены инструкция, шаблон и приёмочные задания; повторная установка и реальные платные подключения в этой доработке не запускались. Для предыдущей 0.2.0 была заявлена проверка установки в чистом изолированном каталоге Linux, без изменения действующего профиля. Windows, macOS и импорт через Desktop отдельно не проверены. Это текстовая инструкция, а не техническая песочница и не гарантия поведения любой модели. Полный набор заданий из `references/checks.md` не объявляется пройденным. Сервисы, сервер и модель могут оплачиваться отдельно; доступ к интенсиву для самого навыка не нужен.

Официальная документация: https://hermes-agent.nousresearch.com/docs/user-guide/features/skills
