# Подбор подключений для Hermes Agent

Бесплатный навык 0.2.0: помогает выбрать самый простой достаточный способ работы с почтой, таблицами, CRM и сайтами. Сначала проверяет уже доступные инструменты, затем при необходимости сравнивает MCP, API, CLI и браузер. Результат — рекомендация с источниками, правами, расходами и безопасным первым тестом. Навык сам ничего не устанавливает и не авторизует.

## Установить одной просьбой агенту

Скопируйте весь блок в разговор с Hermes Agent:

```text
Установи бесплатный навык «Подбор подключений» из https://github.com/artemiimillier/podbor-podklyucheniy. Сначала прочитай README.md и SKILL.md, проверь содержимое и определённую Hermes папку навыков активного профиля. Если одноимённый навык уже есть, не перезаписывай его без моего согласия. Используй штатную команду: hermes skills install https://raw.githubusercontent.com/artemiimillier/podbor-podklyucheniy/v0.2.0/SKILL.md --yes. Не обходи блокировку сканера безопасности. Проверь установленную версию 0.2.0 и наличие SKILL.md, references/checks.md и templates/recommendation.md. Затем найди навык через доступный в этой сборке список навыков и прочитай его. Если текущая сессия ещё не видит новый навык, попроси открыть новый разговор. После установки начни с вопроса: «Какую задачу вы хотите решить и с каким сервисом?» Никакие внешние сервисы пока не подключай.
```

Ручная загрузка архива и распаковка не нужны. Агент выполняет установку в своей среде исполнения: при удалённом Hermes это сервер, а не ноутбук с Desktop. Перед установкой можно попросить агента только прочитать навык, без сохранения.

## Как пользоваться

Например: «Подбирай подключения под задачу без лишних установок. Нужно один раз прочитать публичную страницу. Нужен ли новый MCP?»

Для сложной задачи укажите сервис, нужные действия, разовый или регулярный запуск и ограничения на данные. Не передавайте пароли, токены или коды входа в разговор.

## Что входит

- `SKILL.md` — инструкция навыка.
- `templates/recommendation.md` — необязательный шаблон короткого ответа.
- `references/checks.md` — приёмочные задания, не заявление о пройденных испытаниях.
- `LICENSE` — MIT.

Зависимости и ключи для установки навыка не нужны. Для подбора нужны доступные инструменты чтения публичных источников. Каталог кандидатов: https://smyslokod.ru/mcp. Каждое подключение необходимо проверять отдельно: карточка в каталоге не означает, что доступ уже работает в Hermes.

## Ограничения проверки

Установка проверяется в чистом изолированном каталоге Linux, без изменения действующего профиля. Windows, macOS и импорт через Desktop отдельно не проверены. Это текстовая инструкция, а не техническая песочница и не гарантия поведения любой модели. Полный набор заданий из `references/checks.md` не объявляется пройденным. Сервисы, сервер и модель могут оплачиваться отдельно; доступ к интенсиву для самого навыка не нужен.

Официальная документация: https://hermes-agent.nousresearch.com/docs/user-guide/features/skills
